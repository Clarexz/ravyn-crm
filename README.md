# Ravyn CRM
 
CRM enfocado en clínicas dentales en México. Permite gestionar el registro y seguimiento de pacientes, así como la programación y control de citas, en una sola plataforma.
 
## Stack
 
- **Next.js 14** (App Router) + **TypeScript**
- **Supabase / PostgreSQL** como base de datos y backend
- **Tailwind CSS**
## Funcionalidades (MVP)
 
- Gestión de pacientes (registro, datos de contacto, historial básico)
- Agenda y gestión de citas
